Comment ca marche

Du job au resultat, en trois etapes

Aucune infrastructure a gerer : une console web, une API, et une flotte de noeuds qui se met au travail.

01
console B2BAPI

Soumettez

Vous depositez le job (commande, arguments, nombre de taches) depuis la console. Le cout HT/TTC est simule avant validation - equivalent AWS affiche pour comparer.

02
chunkerschedulinganti-fraude

Distribution automatique

La plateforme decoupe le travail en taches, choisit les noeuds disponibles, verifie leur bonne foi et replanifie toute tache en echec.

03
sandboxSHA-256

Resultat verifie, facture au reel

Chaque tache s'execute en sandbox isole, le resultat est verifie par empreinte. Vous payez la duree GPU reellement consommee, a la seconde.

La stack

GoRust / TauriPostgreSQLNATSDockerCaddy / HTTPS auto

Orchestrateur Go, application desktop Rust (Tauri), persistance PostgreSQL, file NATS, deploiement Docker unifilaire.

Securite par conception

  • Execution sandboxee : pas de reseau, pas d'acces disque hors workspace
  • Allowlist de commandes + timeout d'execution
  • Anti-fraude : empreinte machine, detection Sybil et de lenteur anormale
  • Journalisation complete de chaque centime (client, wallet vendeur, TVA)
